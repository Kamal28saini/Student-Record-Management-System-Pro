
# Student Record Management System Pro

A desktop-based Student Record Management System developed using
Python, Tkinter, and SQLite.

## Features

- Student registration and management
- Update and delete student records
- Search student records
- Marks management
- Attendance management
- Student performance percentage
- Attendance percentage calculation
- CSV report export
- SQLite database
- Dashboard statistics
- Automatic database initialization

## Technologies

- Python
- Tkinter
- SQLite
- CSV
- Pytest

## Installation

Clone the repository:

    git clone https://github.com/Kamal28saini/Student-Record-Management-System-Pro.git

Navigate to the project:

    cd Student-Record-Management-System-Pro

Create virtual environment:

    python3 -m venv .venv

Activate virtual environment on macOS:

    source .venv/bin/activate

Install dependencies:

    pip install -r requirements.txt

Run application:

    python main.py

## Testing

Run tests:

    python -m unittest discover -s tests

## Database

The application automatically creates its SQLite database
inside the database directory.

## Reports

CSV reports are generated inside the project directory.
